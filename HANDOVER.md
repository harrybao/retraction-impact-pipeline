This guide covers two uses: reproducing the analysis from the supplied
dataset, and collecting pages and attention data for selected DOIs.
Both start in R.

## 1. Install the Project and Dataset

Install R matching the version recorded in `renv.lock` (development tests
used R 4.6.1 on Windows), and optionally RStudio. Downloads:
[R](https://cran.r-project.org/) and [RStudio](https://posit.co/download/rstudio-desktop/).

Copy the project to a folder with enough space, then open `cs43.Rproj`.
With internet access, run:

```r
renv::restore()
source("run.R")
cs43_help()
```

Without RStudio, set R's working directory to the project folder and
activate its package environment with `source("renv/activate.R")` before
restoring packages. Package restoration is described in the
[official renv guide](https://rstudio.github.io/renv/articles/renv.html).

On Windows, install the matching Rtools only if restoration asks for
compilation tools. On macOS, source-package installation may need Apple's
command-line development tools. These requirements depend on whether
binaries are available; neither operating system needs a manually installed
Python for the normal R entry point.

### Which Data Is Needed?

| Folder | Contents | Use |
|---|---|---|
| `data/clean/` | Records, citations, attention data, extracted texts | All analyses |
| `data/controls/` | Matched comparison papers | Citation analyses |
| `data/llm/` | Saved model answers | Media and notice analyses |
| `data/labelling/` | Human labels and answer keys | Agreement and validation |
| `data/raw/retraction_watch.csv` | Source records | New collection |
| `data/mhtml/`, `data/pdf/`, `data/interim/` | Saved pages and their database | Viewing collected pages |

The analysis-only project and data require roughly 1.2 GB; the page collection
requires roughly 53 GB in total. These are approximate sizes of the existing
collection, not a promise about future downloads.

The pages package's `data` folder belongs inside the project folder.
Compressed page files should be opened through `save_page()`, not directly.
Some publisher-supplied full texts may be absent from a redistributable copy;
the function explains when an expected licensed file is not included.

This code needs a matching dataset that includes
`data/clean/plumx_notice.csv`. The 9 October package does not contain it
and must not be combined with this revision. A source-only Git clone does
not contain all analysis inputs; `data/share` supplies only a subset.

Before running analyses, check any supplied package checksum lists:

```r
check_package("<package-folder>/SHA256-cs43.csv")
check_package("<package-folder>/SHA256-cs43-pages.csv")
```

Use the actual path to the list. A checksum confirms file integrity, not
that a capture is the right article or that an analysis is correct.

## 2. Reproduce the Tables and Figures

```r
source("run.R")
reproduce_results()
```

This runs 14 analysis scripts, each in its own R process. It reads local
inputs and saved model answers; it does not need API keys, internet access
or a running model server. It writes results to `data/reports` and logs to
`logs/reproduce`, then compares outputs with `data/reports_reference.csv`.

Check `logs/reproduce/steps.csv` for failed scripts and open each named log
in a text editor. `logs/reproduce/reports.csv` identifies files written by
that run and whether they are unchanged, changed or new. Text comparisons
ignore line-ending differences between systems; figures can differ because
of fonts even when table values agree.

| Question | Main Output in `data/reports` |
|---|---|
| Which pages were collected? | `stage1-rendered-pages.csv` |
| How did citations change relative to controls? | `citation-impact-headline.csv`, `citation-impact-event-study.csv` |
| How much did human labellers agree? | `labelling-agreement.csv`, `labelling-round2.csv` |
| How well did the model match labellers? | `llm-validation.csv`, `labelling-round2-model.csv` |
| Did media mention the publication event? | `media-classification-*.csv`, `media-with-notices.csv` |
| How many article DOIs had news mentions? | `news-coverage-union.csv`, `news-coverage-population.csv` |
| What do social-media results cover? | `social-media-*.csv`, including source, date and validation summaries |
| What reasons did notices give? | `notice-classification-*.csv`, `notice-r0-check.csv` |

These names describe outputs generated by this revision, not a claim that
every file is already present in the older package.

The previous 12-script package passed a fresh-copy test on the development
Windows machine on 9 October. This is not acceptance of the current
14-script revision. The current dataset rebuild, complete 14-script run
and new package checksum comparison have not been completed. The revised
source has not been accepted on a fresh macOS or Linux machine.

## 3. Collect Selected DOIs

First-time setup needs internet access:

```r
source("run.R")
use_pipeline_python()
install_browser()
Sys.setenv(RWPIPE_CONTACT = "your.email@example.edu")
```

The contact email defaults to `xbao0816@uni.sydney.edu.au`. It must be a
valid ASCII email address. It identifies API requests; it is not an API key.
Managed Python installation uses the project's `requirements.txt`;
see the [reticulate documentation](https://rstudio.github.io/reticulate/articles/python_packages.html).

```r
res <- run_pipeline(c(
  "10.1371/journal.pone.0066275",  # article DOI
  "10.1155/2016/4835617",          # notice DOI
  "record:70871"                  # both targets for this source record
))
View(res)
View(attr(res, "steps"))
attr(res, "data_dir")             # path to this run's output
```

Inputs must appear in the supplied Retraction Watch CSV. An unknown DOI,
invalid identifier or record with no DOI receives an explanatory result.
Each run accepts at most 1,000 entries, fewer if their combined length is
too large. Split larger lists into smaller batches.

Outputs go to a separate `runs/<date_time>` folder by default. Give a new
`data_dir` to choose another location; do not point sample runs at the
delivered dataset. Reusing a run folder resumes its collection.

The pipeline saves pages, checks identity, tries available alternate
sources, extracts text, and collects citations and attention data.
A blocked publisher or unavailable service can still leave a page missing.
`media = FALSE` omits attention collection. Mass notices can expand to
many article DOIs and take substantially longer than a single-paper run.

The result table is also saved as `run_report.csv`:

| Field | Meaning |
|---|---|
| `doi`, `page` | Target DOI and article, notice or shared-page role |
| `status`, `reason` | Success, refusal or failure, with an explanation |
| `quality` | Full text, notice only, little text or failed extraction |
| `obtained_via` | Browser or alternative source |
| `our_dataset` | How the existing collection holds that target |
| Citation and attention columns | Counts returned by the services; blanks can indicate a failed lookup |

A notice-only page can be a successful capture of the complete short notice,
but it is not the full original article. Some alternate sources provide XML,
HTML or PDF instead of MHTML. Verification does not guarantee full-text access.

### Open a Saved Page

```r
save_page("10.1371/journal.pone.0066275", attr(res, "data_dir"), open = TRUE)
# For the supplied page collection:
save_page("10.1371/journal.pone.0066275", open = TRUE)
```

The unpacked file remains in the run's `pages` folder. Use Chrome or Edge
for MHTML. On macOS the helper selects an installed Chromium-family browser;
it will not hand MHTML to Safari. If none is installed, it leaves the saved
file available and prints a warning. XML, HTML and PDF use the normal file
opening route. macOS browser selection has regression tests, but has not
been verified by opening a real saved page on a Mac.

## 4. API Keys and Access

```r
set_api_keys(altmetric = "your-key",
             elsevier = "your-key",
             elsevier_insttoken = "your-token")
```

Set only the keys you have. These values stay in the R session; do not
include them in a repository or shared package.

| Source | Requirement |
|---|---|
| Altmetric | An API key with the appropriate detail allowance |
| PlumX and Elsevier full text | An Elsevier key and appropriate institutional entitlement |
| Other sources | Availability and access requirements of the selected route |

An API key alone does not prove permission to download or redistribute full
text. Missing keys are reported as failed collection steps, not zero
attention. X/Twitter detail is excluded by default because the project's
key exhausted its separate allowance; use `exclude = NULL` only when your
key permits it.

The analyses read already-collected data. Reclassifying with a local model
is a separate, optional task using `classify_corpus()`; it takes hours and
requires a model server. It is not part of `reproduce_results()`.

## 5. What the Results Can and Cannot Say

The collection has 71,698 source records, 109,888 distinct targets and
96,211 documents marked usable (87.55%). The revised identity and text rules
were applied to it on 17 October 2026: 133 saved pages that were not the
paper asked for were set aside and 15 were restored, and every usable
document's text was extracted again with the repaired extractor.

- Own DOI metadata, an explicitly identified visible DOI or an informative
  title can establish identity. A DOI in a request URL, toolbar or references
  cannot. Reviewed aliases are document- and role-specific; a related
  notice or old article version is not automatically the requested paper.
- Some existing notice texts contain method/clinical passages or trailing
  page material. Notice-reason results from those texts need caution until
  the corrected extractor is applied and affected model answers are renewed.
  Even corrected outputs can retain notice links or malformed text already
  present in a saved page; extraction is not a guarantee of complete cleanliness.
- News counts describe DOI mentions, not unique stories or necessarily
  retraction reporting. Across both providers and article/notice routes,
  9,006 of 62,867 original DOIs have tracked news: 8,249 have a Retraction
  record and 757 do not. Failed lookups remain unknown.
  Altmetric summary counts do not guarantee readable post text; placeholder
  titles and missing text must be checked in the post-level analysis.
- Retraction Watch includes other event types. The saved model prompt
  assumes the paper was retracted, which is inappropriate for corrections
  and expressions of concern. Retraction-only results are shown separately,
  but old classifications have not been repaired by a new prompt.
- Social-media counts use one representative deduplicated item and a stated
  event date. Results based on all event types differ from Retraction-only
  results. Unreadable items and validation sample limits are reported
  separately; validation for news/blogs or selected social sources does not
  validate every platform. X identifiers and dates are not tweet text.
- Citation estimates cover eligible papers and available yearly citation
  windows, not all papers. Pre-event trends, control availability and
  selection affect interpretation; the estimates are not a pure causal effect.
- Blocks and incomplete service coverage are reported gaps. Files supplied
  under publisher agreements may have separate redistribution restrictions.

## 6. Protect the Existing Dataset

`rebuild_all()` shows the collection plan. Only
`rebuild_all(confirm = TRUE)` executes it and changes the dataset.

Identity checking in R is read-only by default:
`verify_archives()`; use `apply = TRUE` only for an approved update.
Replacing text extracted with older rules requires
`extract_text(upgrade = TRUE)`. Back up and verify the database first.

After an approved update, regenerate clean inputs, affected model answers,
all 14 analyses and the result reference together. Publish the source,
matching data and checksum lists as one consistent package, retaining the
older package. Until that acceptance is complete, use the existing package
with its original matching source, not a mixture of revisions.

For troubleshooting, send the failed step's log and `run_report.csv` or
`logs/reproduce/steps.csv`. Do not send API keys.
